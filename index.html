    GitHub 토큰 발급 방법

    1. 토큰 발급 페이지 열기 — Fine-grained token(세분화된 토큰)을 만듭니다.
    2. Token name은 알아보기 쉬운 이름(예: my-todo 홈페이지), Expiration은 90 days를 고릅니다.
    3. Repository access에서 Only select repositories → my-todo만 선택합니다.
    4. Permissions → Repository permissions → Issues: Read and write로 바꿉니다. (Metadata: Read-only는 자동 포함)
    5. Generate token을 누르고, 표시된 토큰을 복사해 아래 칸에 붙여 넣은 뒤 [저장]을 누릅니다.

    토큰은 이 브라우저(localStorage)에만 저장되고 api.github.com 외에는 보내지 않습니다. 공용 PC에서는 사용 후 [삭제]를 누르세요. 90일 뒤 만료되면 같은 방법으로 새로 발급해 저장하세요.

    입력 방법

    • 완료: 끝을 완료 · 끝 · 다 했어 · done으로 — 예) 견적서 송부 완료, #3 끝
    • 대기: 끝을 대기 · 대기 중 · 기다리는 중으로 — 예) 고객 회신 대기
    • 반복: 매일 · 평일마다 · 매주 월요일 · 매월 15일 — 예) 매주 월요일 주간보고 작성하기 (회차는 해당일 아침 07:50 자동 작업이 할 일로 만듭니다)
